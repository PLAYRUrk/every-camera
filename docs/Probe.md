# Опрос камеры

`--probe` показывает, что видит программа, и завершается. Работает для `asi`, `japan` и `sptt`.

```bash
python main.py --type asi --probe
python main.py --type japan --probe
python main.py --type sptt --probe
```

## ASI

Открывает камеру и печатает модель, серийный номер, размер сенсора и допустимые значения каждого параметра, который выставляет драйвер: уставка охлаждения, скорость АЦП, усиление, режимы затвора и считывания, выдержка.

В камеру ничего не записывается, поэтому команда работает и тогда, когда запуск падает на «Invalid Parameter Value».

## Japan

Показывает, видит ли DCAM камеру, и печатает таблицу по `EXPOSURETIME`, `BINNING`, `READOUTSPEED`, `SENSORTEMPERATURE` и параметрам кулера.

Затем команда **прогоняет колесо фильтров**: возвращает его домой, переводит на позиции 1, 5 и 3 и печатает сырые ответы контроллера с временем. Так проверяется протокол `GOSUB4` → `FILT:<n>` и реальное время перехода.

> В камеру ничего не пишется, но колесо физически двигается. Не запускайте команду во время ночных измерений.

При `backend = "sim"` или `port = "sim"` соответствующая часть пропускается с пояснением.

## SPTT

Перечисляет подключённые камеры и их USB-порты для ключа `sptt.usb_port`. Команда ничего не открывает и не загружает, поэтому безопасна при работающих камерах.

```
USB port    Model      State
1-1.2       CSDU-429   firmware loaded
1-1.3       CSDU-285C  no firmware yet
```

## Недопустимые значения

Ограничения у каждой модели свои. Значение из `config.json`, которое камера не принимает, обрабатывается по-разному:

| Что | Поведение |
|---|---|
| Измеряемые величины: уставка, скорость АЦП, высота окна Kinetics | подтягиваются к ближайшему допустимому значению с предупреждением |
| Режимы: затвор, считывание, выходной сигнал, усиление | запуск прекращается с перечнем допустимых значений |
| Выдержка | не подрезается: укороченная экспозиция незаметно испортила бы измерение |

Пример предупреждения:

```
[WARN ] Sensor setpoint (°C): this camera does not accept -60 (allowed: -55 … 25, step 0.1) — using -55 instead
```

Режимы не заменяются ближайшими, потому что соседний номер — это другой режим.
