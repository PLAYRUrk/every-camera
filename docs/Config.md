# Конфигурация

Настройки станции лежат в `config.json` в корне программы. Файл создаётся при первом запуске. Заполнять его удобнее [мастером настройки](Setup-Wizard.md).

> `config.json` — настоящие настройки станции. GUI перезаписывает его при закрытии окна. Для экспериментов используйте отдельный файл: `--config /path/to/test.json`.

## Устройство файла

Верхний уровень: по секции на камеру, секции `alerts` и `server` и два общих ключа.

```json
{
  "cannon": { },
  "sptt": { },
  "infra": { },
  "sentry": { },
  "asi": { },
  "japan": { },
  "alerts": { "to": ["ivanov@example.ru"] },
  "server": { "port": 8765 },
  "node_name": "Tory-1",
  "status_dir": ""
}
```

| Секция | Описание |
|---|---|
| `cannon` | [Canon](Camera-Canon.md#параметры) |
| `sptt` | [SPTT](Camera-SPTT.md#параметры) |
| `infra` | [Infra](Camera-Infra.md#параметры) |
| `sentry` | [Sentry](Camera-Sentry.md#параметры) |
| `asi` | [ASI](Camera-ASI.md#параметры) |
| `japan` | [Japan](Camera-Japan.md#параметры) |
| `alerts` | [Оповещения](Alerts.md#параметры) |
| `server` | [HTTP-сервер кадров](Frame-Server.md#параметры) |

## Общие ключи

| Ключ | По умолчанию | Описание |
|---|---|---|
| `node_name` | `""` | понятное имя машины, например `Tory-1`; пусто — имя хоста. См. [Имя узла](Node-Name.md) |
| `status_dir` | `""` | каталог JSON-файлов статуса; пусто — `~/.every_camera/status` |

## Файлы в домашнем каталоге

Рабочие данные программы лежат в `~/.every_camera/`:

| Каталог или файл | Содержимое |
|---|---|
| `logs/` | логи: `{камера}_{экземпляр}.log` |
| `status/` | файлы статуса |
| `instances/` | блокировки имён экземпляров |
| `outbox/` | очередь писем |
| `peers/` | реестр увиденных узлов |
| `mail_account.json` | учётная запись отправителя писем |

## Машинное окружение

Пути к SDK, интерпретатор и активация conda задаются не в `config.json`, а в `env.sh` или `env.cmd`: см. [Скрипт запуска](Run-Script.md).
