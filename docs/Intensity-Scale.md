# Шкала интенсивности

Все камеры отдают кадры в одном диапазоне **0–65535**, как 16-битный АЦП. Драйвер приводит значения сразу после захвата, поэтому статистика, гистограммы, доля насыщенных пикселей, автоэкспозиция и отображение везде означают одно и то же.

| Камера | Исходные данные |
|---|---|
| SPTT (CSDU-429), Infra (Tanho SWIR) | 12 бит |
| Canon | 8-битный JPEG |
| ASI (PIXIS), Japan (Hamamatsu) | 16 бит |

## Преобразование

Младшие биты дополняются старшими. Для 12 бит: `(v << 4) | (v >> 8)`.

Нулю соответствует нуль, полной шкале сенсора — ровно 65535, а исходный отсчёт восстанавливается сдвигом вправо. Простой сдвиг `<< 4` оставил бы насыщенный пиксель на 65520, и проверка пересвета его бы не увидела.

## Шкала в файле

Каждый кадр несёт свою шкалу в FITS-заголовке:

```
ADCFULL =                65535 / [ADU] intensity full scale
```

Кадры без этого ключа считаются 12-битными. При просмотре они приводятся к 0–65535 на лету, файлы на диске не меняются.

> **Внешним программам обработки.** Значения в файлах с ключом `ADCFULL` отличаются от старых примерно в 16 раз. Файл без ключа читайте как 12-битный.

## Исключения

Canon и Sentry не приводятся при записи: JPEG остаётся 8-битным, а FITS пишет демон `imagerd_rt`. Статистика в `viewer_app.py` для них всё равно приводится к общей шкале.
