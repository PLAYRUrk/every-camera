# Телеметрия

Каждая камера автоматически пишет телеметрию в CSV. Настраивать ничего не нужно, ключей конфига нет.

Файлы лежат в `~/.every_camera/telemetry/`:

```text
<экземпляр>_ГГГГММДД.csv
<экземпляр>_ГГГГММДД_part2.csv
```

Новый файл начинается каждые сутки UTC. В первой колонке `time_utc`, дальше все поля статуса камеры: режим, экспозиция, фильтр, температуры, счётчики кадров и ошибок, свободное место и другие. Вложенные значения разворачиваются: `system.disk_free_mb`, `omega.value`. Для ASI сюда же попадают данные [Omega](Camera-ASI.md#omega-cni3223-c24).

Строка добавляется раз в 5 секунд и при каждой смене статуса. Если у камеры появилось поле, которого нет в шапке, например Omega ответила позже запуска, запись продолжается в следующей части `_partN`: старый файл остаётся корректным CSV.

Ошибка записи, например переполненный диск, даёт одно предупреждение в журнале. Измерения продолжаются.
