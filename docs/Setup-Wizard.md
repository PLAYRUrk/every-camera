# Мастер настройки

`setup_app.py` читает и записывает тот же `config.json`, что использует `main.py`.

```bash
python setup_app.py                         # все камеры
python setup_app.py --type asi              # только одна камера
python setup_app.py --config /path/to.json  # другой файл
python setup_app.py --console               # в терминале
```

Без дисплея программа сама переходит в консольный режим.

## Вкладки

| Вкладка | Что настраивает |
|---|---|
| Canon, SPTT, Infra | параметры камеры. На вкладке SPTT кнопка **Find…** ищет USB-порты камер |
| Sentry | параметры и таблица слотов: **Add slot**, **Remove selected**, **Move up/down** |
| ASI | камера, охлаждение, колесо фильтров, координаты, таблица слотов |
| Japan | то же, но короче: нет усиления. Задаются название прибора (`name`) и места съёмки (`location.name`) |
| Оповещения | адреса получателей, кнопка **Отправить тестовое письмо**; см. [Оповещения](Alerts.md) |
| LAN Server | [HTTP-сервер кадров](Frame-Server.md) |
| General | [имя узла](Node-Name.md) и каталог статусов |

Особенности вкладок ASI и Japan:

- В таблице ASI колонки `Delta` и `Binning` работают в режиме `time`, колонка `Seconds` — в режиме `sun`. В таблице Japan `Delta` работает в режимах `time` и `sun_cycle`.
- Поле `T_start` означает местное время в режиме `time` и **UTC** в режиме `sun_cycle`.
- Группа **Intensity control** настраивает [управление интенсивностью](Intensity-Control.md). На вкладке Japan она подписана «sun_cycle mode only»: разбиение слота у этой камеры в режиме `time` не работает.

Кнопки окна: **Save** (при ошибке записи сообщает о сбое), **Load config…** (окно перестраивается и сразу показывает значения загруженного файла), **Reset to defaults** (фильтр `--type` сохраняется), **Close**.

- Ключи, добавленные в файл вручную и не показанные ни в одной форме, при сохранении остаются.
-
- Пустые ячейки Gain/Readout/Binning в таблице слотов ASI (Binning в Japan) означают «не задано, брать настройку камеры» и остаются пустыми.
- Browse у «Legacy schedule file» открывает выбор файла.

## Консольный режим

```bash
python setup_app.py --console                      # выбор камеры в начале
python setup_app.py --console --type infra         # одна камера
python setup_app.py --console --config /path/to.json
```

Мастер задаёт вопросы с подсказками и значениями по умолчанию, а в конце спрашивает настройки LAN-сервера и адреса оповещений. Enter оставляет текущее значение; ответ `-` очищает необязательные значения (`period_us` и `trigmode` у SPTT; `t_start` в `sun_cycle` у ASI и Japan становится первой целой минутой окна).

## Автоматический запуск

Если у камеры Canon, SPTT или Infra не задан `output_dir`, `main.py` в консольном режиме сам запускает мастер для этой камеры. Имя экземпляра, введённое в мастере, применится при следующем запуске.

Отсутствие расписания мастер не вызывает: такая камера поднимается в [режиме настройки](Setup-Mode.md).
