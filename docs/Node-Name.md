# Имя узла

Ключ `node_name` задаёт понятное имя машины, которое видит наблюдатель вместо IP-адреса:

```json
{ "node_name": "Tory-1" }
```

Имя описывает **машину**, а не камеру: на одном узле может работать несколько камер. Если ключ не задан, используется имя хоста, поэтому поле никогда не бывает пустым.

Задать имя можно в `setup_app.py` (вкладка **General**, поле «Node name») или в консольном мастере при настройке LAN-сервера.

## Где видно имя

- В ответе на UDP-обнаружение:

  ```
  $ python discovery.py --timeout 2
  Tory-1               ASI_Tory-1           asi      http://192.168.1.42:8765
  ```

- В `/api/info` и `/api/status` LAN-сервера и в файлах статуса.
- В `viewer_app.py` и `focus_app.py`. Камеры в списке подписаны `Tory-1 — ASI_Tory-1 (asi) — 192.168.1.42:8765`, список отсортирован по имени узла.
- В мониторе на плитке камеры. Во вкладке **Monitor** в `gui_app.py` имя показано в колонке «Extra Info» как `@Tory-1`.

Имя узла также входит в [имя экземпляра](Multi-Instance.md#имя-экземпляра) по умолчанию.
