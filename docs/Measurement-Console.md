# Консоль измерений

В консольном режиме программа рисует один живой экран, который перерисовывается на месте. Экран одинаков для всех камер, меняется только блок `camera`.

```
================================================================
 EVERY CAMERA — ASI @ Tory-1  (ASI_Tory-1)
================================================================
  Time:                     21:04:33
  Status:                   running  (cycle 12, Δ100 s)
  Phase:                    measuring
  Schedule:                 cycle 160 s from 20:00:00  ·  iteration 12
  Next frame:               21:05:00  (in 27.0 s)
  Capturing:                LIGHT filter=3   12.4 s / 25 s
  Frames captured:          128 light / 6 dark        errors 0
  Last file:                20260727_210400_TORY_ASI0_OH___025000ms.fits
  Output dir:               /data/asi  (812.5 GB free)
  ---- camera ----------------------------------------------------
  Exposure / binning:       25 s  ·  2x2
  Gain:                     3
  Filter:                   3
  Sensor temperature:       -59.83 °C   setpoint -60.0 °C (locked)
  ---- network ---------------------------------------------------
  LAN server:               http://192.168.1.42:8765/   name: Tory-1
  Live view / focus:        active
  Alerts:                   obs-alerts@yandex.ru → 2 адресата
----------------------------------------------------------------
  21:04:30 [INFO ] Saved 20260727_210400_TORY_ASI0_OH___025000ms.fits
  21:04:12 [INFO ] Filter 3 reached in 1.1 s
  21:04:05 [WARN ] Filter wheel did not confirm position 5 within 8 s
                   (it reports nothing) — retrying
================================================================
  Ctrl+C — finish the frame, shoot the closing darks, stop
```

| Строка | Значение |
|---|---|
| `Time` | часы, идут независимо от съёмки |
| `Status`, `Phase` | состояние воркера и текущая фаза: ожидание, тёмные кадры, измерения |
| `Schedule` | режим расписания: окно по Солнцу или период цикла |
| `Next frame` | время следующего кадра и обратный отсчёт |
| `Capturing` | что снимается сейчас и сколько секунд экспозиции прошло |
| `Frames captured` | счётчики кадров и ошибок за сеанс |
| `Last file` | последний записанный файл |
| `Output dir` | каталог архива и свободное место |
| блок `camera` | экспозиция, биннинг, усиление, фильтр, температура |
| блок `network` | адрес LAN-сервера, имя узла, живой просмотр, оповещения |
| нижняя панель | последние строки лога |

Отрисовка идёт в отдельном потоке и читает только словарь состояния, а к камере не обращается. Поэтому во время экспозиции часы и счётчик `Capturing` продолжают идти.

Все сообщения драйверов попадают в нижнюю панель и файл лога. Строки, которые печатают сторонние библиотеки, тоже перехватываются и не портят экран.

## Файл лога

Полный лог всегда пишется в `~/.every_camera/logs/{камера}_{экземпляр}.log`, независимо от режима отображения. Ротация — по 2 МБ, один архивный файл `.log.1`.

## Плоский режим

```bash
python main.py --type asi --verbose
```

Живой экран заменяется строками `ЧЧ:ММ:СС [УРОВЕНЬ] сообщение`. То же происходит автоматически, если вывод не является терминалом: systemd, `nohup`, конвейер.
