# Камера ASI

Всенебный имиджер: ПЗС-камера Princeton Instruments PIXIS через PICAM SDK и колесо фильтров Animatics SmartMotor по последовательному порту. Драйвер работает с оборудованием напрямую, без демона `imagerd_rt`.

```bash
python main.py --type asi
```

Без оборудования драйвер работает с `camera.backend = "sim"` и `filter_wheel.port = "sim"`.

## Подключение

Права на USB-устройство камеры настраивает установщик SDK Princeton Instruments. Отдельно нужен доступ к порту колеса:

```bash
sudo usermod -aG dialout $USER      # затем перелогиниться
ls -l /dev/ttyUSB0                  # группа должна быть dialout
```

Если библиотека лежит не в стандартном каталоге, укажите файл:

```bash
export PICAM_LIB=/opt/PrincetonInstruments/picam/runtime/libpicam.so
```

Для GigE-камер нужны переменные eBUS и GenICam в `env.sh`: см. [Скрипт запуска](Run-Script.md#переменные-sdk-для-asi). На CentOS 7 см. также [установку](Install-CentOS.md). На Windows камера не поддерживается.

### filter_wheel

| Ключ | По умолчанию | Описание |
|---|---|---|
| `port` | `/dev/ttyUSB0` | порт контроллера; `sim` — симулятор |
| `baudrate` | `9600` | скорость порта |
| `move_timeout` | `8.0` | ожидание подтверждения для одной попытки поворота, с |

На Linux лучше указывать устойчивое имя порта: см. [Камера Japan](Camera-Japan.md#имя-порта).

Обычный поворот занимает около секунды. Если подтверждения нет, программа по порядку:

1. спрашивает контроллер, где колесо (`GOSUB4`);
2. повторяет поворот;
3. переоткрывает порт и уводит колесо домой, около десяти секунд.

Если ничего не помогло, позиция считается неизвестной: кадр не помечается этим фильтром, ошибка попадает в лог, счётчик на дашборде и `/api/status`.

- Состояние затвора колеса считается неизвестным, если контроллер не подтвердил команду. Если затвор закрыть не удалось, тёмные кадры пропускаются, а не записываются как DARK.
- Если переходник USB-serial колеса отвалился, порт переоткрывается, а не отказывает каждый слот.
- Последовательные порты (колесо, Omega) на Linux открываются эксклюзивно. Автопоиск Omega (`auto`) никогда не трогает порт колеса, даже если он задан как `/dev/serial/by-id/…` или в другом регистре.

### omega

Регулятор температуры корпуса колеса, см. [Omega CNi3223-C24](#omega-cni3223-c24).

| Ключ | По умолчанию | Описание |
|---|---|---|
| `port` | `"auto"` | порт; `"auto"` ищет Omega среди USB-COM переходников, кроме порта колеса; `"sim"` — симулятор; `""` — не опрашивать |
| `baudrate` | `9600` | скорость порта |
| `poll_seconds` | `10.0` | период опроса, с |

### location

`lat`, `lon`, `elevation` — координаты станции. Записываются в шапку FITS и нужны для расчёта высоты Солнца.

## Имена файлов

Кадры раскладываются по дате **в UTC**. Ночь разрезается по полуночи UTC.

```
<output_dir>/2026/07/28/20260728_203000_TORY_ASI0_5577_055000ms.fits
<output_dir>/2026/07/28/20260728_202000_TORY_ASI0_OH___007000ms_DARK.fits
<output_dir>/2026/07/28/20260728_193000_TORY_ASI0_5577_000500ms_pf.fits
<output_dir>/seqno.txt
```

Формат: `ГГГГММДД_ччммсс_<site_id>_<device_id>_<тег фильтра>_<экспозиция в мс, 6 цифр>ms[_DARK][_pf].fits`.

- Если позиция колеса неизвестна, вместо тега пишется `none`. Так бывает у первых тёмных кадров на home-позиции.
- `_pf` — кадр [предварительной стадии](Intensity-Control.md#предварительная-стадия-preflight).
- `seqno.txt` — сквозной счётчик кадров (карта `SEQNO`), он переживает перезапуски. При переезде со старой программы скопируйте её `aux/seqno.txt` в `output_dir`, и нумерация продолжится.

## Шапка FITS

Основной набор: `DATE-OBS` (UTC, начало экспозиции), `DATE-LOC` (местное время), `EXPTIME`, `BINNING`, `READSPD`, `FILTER`, `CCD-TEMP`, `SETTEMP`, `GAIN`, `IMAGETYP` (`LIGHT`, `DARK`), `OBSMODE` (`sun`, `time`, `sun_cycle`, `sun_cycle_auto`, `dark`), `INSTRUME`, `VENDOR`, `CAMSN`, `CAMVER`, `DRVVER`, `DCAMVER`, `SITELAT`, `SITELON`, `SITEELEV`.

Карты управления интенсивностью: `SKYMEAN`, `SPLITNUM`, `SPLITIDX`.

Дополнительно пишутся 16 полей `imagerd_rt` под теми же именами, их читает программа обработки:

| Имя | Значение |
|---|---|
| `Binning` | биннинг |
| `BitDepth` | разрядность сенсора |
| `CCDGain` | усиление 1–3 |
| `CCDTemp` | температура ПЗС, °C, округлена до сотых |
| `Exposure` | **строка** вида `"55000.00 ms"` |
| `ReadoutSpeed` | **строка** `"2 MHz"` или `"100 KHz"` |
| `SEQNO` | номер кадра |
| `SiteID` | `asi.site_id` |
| `DeviceID` | `asi.device_id` |
| `Latitude`, `Longitude` | координаты, округлены до сотых |
| `FilterWavelength` | тег фильтра (`5577`, `OH__`, …) |
| `FilterPosition` | позиция колеса |
| `FilterDescription` | описание фильтра |
| `FWTemp` | температура корпуса колеса от Omega; без неё `fw_temp`, иначе `-999.0` |
| `Version` | `asi.legacy_version` |

Имена длиннее 8 символов записаны как HIERARCH-карты, написание сохраняется точно. `astropy` читает их по тому же имени: `header["FilterWavelength"]`.

## Omega CNi3223-C24

Омега подключена через второй переходник COM→USB и держит температуру корпуса колеса. Порт: 9600, 7 бит, нечётность, 1 стоповый, RS-232, протокол iSeries (заводские настройки регулятора).

Программа только читает: температуру, пик и минимум, уставки 1 и 2, тревоги, PID. Команд записи в коде нет, поэтому настройки регулятора не меняются.

Показания попадают в статус, [телеметрию](Telemetry.md) и `FWTemp` в FITS. Показание старше минуты в FITS не идёт. Если Omega молчит, съёмка продолжается: в журнале одно предупреждение, порт переоткрывается каждые 30 с.

## Проверка колеса на столе

`filterwheel_bench.py` проверяет контроллер колеса и Omega без камеры:

```bash
python filterwheel_bench.py ports                         # какие порты что отвечают
python filterwheel_bench.py ping --port /dev/ttyUSB0 --count 100
python filterwheel_bench.py positions --port /dev/ttyUSB0
python filterwheel_bench.py cycle --port /dev/ttyUSB0 --count 0
python filterwheel_bench.py omega --port /dev/ttyUSB1 --watch
```

| Режим | Что делает |
|---|---|
| `ports` | список USB-COM портов и что на них отвечает |
| `ping` | опрос положения: потери и время ответа |
| `home` | увод колеса домой |
| `positions` | все положения 1–6 с контролем прихода |
| `cycle` | непрерывно по кругу |
| `random` | случайные переходы |
| `pair A B` | многократная смена двух положений |
| `shutter` | циклы открытия и закрытия затвора |
| `soak` | длительный опрос с редкими поворотами, как ночью |
| `omega` | все параметры Omega; `--watch` — непрерывно |

`--count N` задаёт число повторов, `--count 0` работает до Ctrl-C. `--pause` — пауза между операциями, `--csv файл` — запись каждой операции, `--sim` — без оборудования. В конце выводится сводка; код возврата `0`, если сбоев не было.

Программа измерений при этом должна быть остановлена: порт может открыть только один процесс.
