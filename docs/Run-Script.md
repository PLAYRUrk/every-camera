# Скрипт запуска

`run.sh` — обёртка над `main.py`. Всё после имени скрипта передаётся как есть, поэтому она заменяет `python3 main.py`. На Windows то же делает [`run.cmd`](Install-Windows.md#запуск).

```bash
./run.sh --type asi
./run.sh --type asi --config /etc/every-camera/asi.json
./run.sh --gui
./run.sh --sentinel          # сторож вместо камеры
```

Что делает скрипт:

- переходит в каталог программы, чтобы относительные пути были предсказуемы;
- подхватывает `env.sh`, если он есть;
- выбирает интерпретатор: переменная `PYTHON`, venv рядом с программой (`venv/`, `.venv/`), `python3` из `PATH`;
- запускает программу через `exec`.

`exec` важен: без него `SIGTERM` от `systemctl stop` попал бы в bash, а Python остался бы без штатного завершения, финальных тёмных кадров и отогрева сенсора.

## env.sh

В `env.sh` складывается всё машинно-зависимое: пути SDK, активация conda, выбор интерпретатора. Файл в `.gitignore`, образец — `env.sh.example`:

```bash
cp env.sh.example env.sh   # и поправить под свою машину
```

Через `run.sh` запускается и служба systemd, поэтому окружение описывается один раз, и запуск руками совпадает с запуском службой.

## Переменные SDK для ASI

Драйвер грузит `libpicam.so` через ctypes, а PICAM для GigE-камер использует рантайм eBUS. Эти переменные читает не Python, а нативные библиотеки. Логин-шелл их ставит, а служба не получает. Это самая частая причина, почему камера работает руками и не работает под systemd. Готовый блок — в `env.sh.example`.

**Кэш GenICam** (`GENICAM_CACHE_V2_4`). Каталог должен быть записываемым, GenICam не создаёт его сам. Не кладите его в общий `/tmp/genicam_cache_v2_4`: служба работает от root, оператор запускает программу от себя, и второй не сможет туда писать. Используйте путь внутри `$HOME`.

## Пути к библиотекам камер

Обе переменные необязательны. В отличие от `LD_LIBRARY_PATH`, они называют **файл**, а не каталог. При неудачной загрузке ошибка перечисляет все опробованные пути.

| Переменная | Камера | Где ищется по умолчанию |
|---|---|---|
| `PICAM_LIB` | ASI | `libpicam.so`, `/usr/local/lib/libpicam.so`, `/opt/PrincetonInstruments/picam/runtime/libpicam.so`, `/usr/local/lib/picam/libpicam.so` |
| `DCAM_LIB` | Japan | Linux: `/usr/local/lib/libdcamapi.so`, затем `libdcamapi.so` по путям загрузчика. Windows: `dcamapi.dll` |

Другие переменные: `EVERY_CAMERA_IERS_AUTO`, см. [Солнце и IERS](Sun-And-IERS.md#если-нужна-свежая-таблица).

## Автозапуск

Запускать скрипт через `cron @reboot` или `rc.local` можно, но тогда не будет перезапуска при падении, `systemctl status`, журнала и таймаута на остановку при выключении ПК. Для станции используйте [службу systemd](Systemd.md).
