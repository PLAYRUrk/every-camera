# Камера Japan

Всенебный имиджер: камера Hamamatsu через DCAM-API и то же колесо фильтров Animatics SmartMotor, что у ASI. Единственная камера, полностью работающая и на [Windows](Install-Windows.md).

```bash
python main.py --type japan
```

Программа измерений проще программы ASI: нет аналогового усиления, а охлаждение — только выключатель. Режим `sun_cycle` работает по правилам ASI: архив в том же формате и обе функции [управления интенсивностью](Intensity-Control.md). Сравнение камер: [Общее у ASI и Japan](ASI-Japan-Shared.md).

Без оборудования драйвер работает с `camera.backend = "sim"` и `filter_wheel.port = "sim"`.

## Подключение

Драйвер использует `libdcamapi.so` из DCAM-API SDK. Библиотеку ставит установщик SDK, обычно в `/usr/local/lib`. Обёртки Hamamatsu уже лежат в `cameras/japan/dcamsdk/vendor/`.

Доступ к порту колеса:

```bash
sudo usermod -aG dialout $USER      # затем перелогиниться
ls -l /dev/ttyUSB0                  # группа должна быть dialout
```

Если библиотека лежит не в стандартном каталоге, укажите файл. `LD_LIBRARY_PATH` здесь не поможет.

```bash
export DCAM_LIB=/opt/hamamatsu/dcam/libdcamapi.so
```

Для службы пропишите переменную в `env.sh`. При неудачной загрузке драйвер печатает все опробованные пути.

## Параметры

| Ключ | По умолчанию | Описание |
|---|---|---|
| `instance_name` | `""` | имя экземпляра; пусто — `JAPAN_<узел>` |
| `output_dir` | `""` | `sun`, `time`: кадры пишутся плоско, обычно это каталог на ночь (`/data/japan/20260729/`). `sun_cycle`: дерево `YYYY/MM/DD` |
| `name` | `""` | название прибора: карта `NAME` и имя файла `sun_cycle` |
| `mode` | `sun` | `sun`, `time` или `sun_cycle`; неизвестное значение сообщается при запуске и заменяется на `sun` |
| `sun_max_angle` | `-10.0` | `sun`, `sun_cycle`: съёмка идёт, пока высота Солнца не больше этого значения, градусы |
| `t_start` | `20:00` | опорное время цикла: местное в `time`, **UTC** в `sun_cycle` |
| `schedule_len` | `null` | период цикла, с; `null` или `0` — вычисляется по слотам. Лучше указывать [в самом файле](Schedules.md#период-в-самом-файле) |
| `dark_frames` | `3` | тёмных кадров на каждую уникальную экспозицию |
| `dead_time` | `5.0` | время на смену фильтра и биннинга, входит в период, с |
| `wait_for_enter` | `true` | `time`: ждать Enter перед стартом. На фокусировку не влияет |
| `schedule` | `[]` | [слоты расписания](Schedules.md) |
| `schedule_file` | `""` | старый `schedule.txt` или `.json`, заменяет `schedule` |
| `filters` | `[]` | таблица колеса для `sun_cycle`; пусто — [колесо Тори](Camera-ASI.md#позиции-фильтров) |
| `preflight` | выключена | только `sun_cycle`, см. [Управление интенсивностью](Intensity-Control.md); `binning` здесь 1–8 |
| `overexposure` | выключена | **только `sun_cycle`**, см. там же |

Символы `_`, `/`, `\`, пробел и подобные в `name` и `location.name` заменяются на `-`, иначе сломался бы разбор имени файла. Об этом сообщается при запуске. В `sun_cycle` пустые значения заменяются на `JAPAN` и `SITE` с предупреждением.

Элемент `filters`: `{"slot": 1, "wavelength": "5577", "description": "557.7nm x 2.0nm"}`.

Ошибка в `preflight` или `overexposure` выключает соответствующую функцию и сообщается при запуске. Сообщения начинаются с `japan.`.

### camera

| Ключ | По умолчанию | Описание |
|---|---|---|
| `backend` | `dcam` | `dcam` или `sim` |
| `readout_speed` | `2` | `READOUTSPEED`: `1` — медленная, минимум шума; `2` — быстрая |
| `binning` | `1` | биннинг, 1–8 |
| `frame_timeout_ms` | `1000` | одно ожидание готовности кадра в DCAM |

Драйвер ждёт несколько окон `frame_timeout_ms` сверх экспозиции и только потом бросает кадр, поэтому зависшая камера не подвешивает программу.

### cooling

Управление кулером Hamamatsu через DCAM (`SENSORCOOLER`). По умолчанию выключено: камера охлаждается сама. Значения по умолчанию заданы в программе, в `config.json` секцию можно не писать.

| Ключ | По умолчанию | Описание |
|---|---|---|
| `enabled` | `false` | включить управление |
| `lead_minutes` | `30` | `sun`, `sun_cycle`: кулер включается за столько минут до предварительных тёмных кадров |
| `target_temp` | `null` | уставка, °C; `null` — оставить уставку камеры. Работает, если модель даёт писать `SENSORTEMPERATURETARGET` |
| `tolerance` | `3.0` | допустимое отличие от уставки к началу тёмных кадров |
| `off_between_nights` | `true` | выключать кулер, когда ночь закончилась |
| `off_on_exit` | `true` | выключать кулер при выходе, после финальных тёмных кадров |

- Если температура не успела выйти на уставку, в лог идёт предупреждение, но тёмные кадры начинаются вовремя.
- В режимах `time` и `--setup` кулер включается при старте и работает до выхода.
- Возможности модели показывает [`--probe`](Probe.md): строки `SENSORCOOLER`, `SENSORTEMPERATURETARGET`, `SENSORCOOLERSTATUS`.
- Если `SENSORCOOLER` недоступен на запись, выводится предупреждение, и камера продолжает охлаждаться сама.

### filter_wheel

Те же ключи и то же поведение при сбое, что [у ASI](Camera-ASI.md#filter_wheel). На Windows порт — `COM3`, `COM5` и так далее.

#### Имя порта

На Linux лучше указывать устойчивое имя:

```bash
ls -l /dev/serial/by-id/
# usb-FTDI_FT232R_USB_UART_A50285BI-if00-port0 -> ../../ttyUSB0
```

Имена `ttyUSB*` выдаются в порядке появления устройств, и после перезагрузки `ttyUSB0` может достаться другому переходнику. Такой порт откроется без ошибок, но отвечать будет некому, и ночь уйдёт в архив без меток фильтров.

### location

| Ключ | Описание |
|---|---|
| `name` | название места, например `TORY`: поле площадки в имени файла `sun_cycle`, карта `SiteID` |
| `lat`, `lon` | широта и долгота, градусы |
| `elevation` | высота над уровнем моря, м |

Координаты нужны режимам `sun` и `sun_cycle` и пишутся в шапку каждого кадра.

## Имена файлов

### sun и time

Кадры пишутся плоско в `output_dir`. Метка времени — **UTC**.

```
20260729T140530_3.fits      измерение, фильтр 3
20260729T140530_3_bg.fits   тёмный кадр
```

Позиция `0` означает «дома» либо «неизвестно».

Тёмные кадры идут подряд, а имя различает только секунды. Если имя занято, оно сдвигается на секунду вперёд до свободного. `DATE-OBS` при этом хранит настоящий момент начала экспозиции.

### sun_cycle

Имена и дерево как [у ASI](Camera-ASI.md#имена-файлов), где площадка — `location.name`, прибор — `name`, тег фильтра — из `filters`:

```
<output_dir>/2026/07/28/20260728_203000_TORY_HAMA1_5577_055000ms.fits
<output_dir>/2026/07/28/20260728_202000_TORY_HAMA1_OH___007000ms_DARK.fits
<output_dir>/seqno.txt
```

`viewer_app.py` разбирает оба вида имён.

## Шапка FITS

### sun и time

18 общих карт за вычетом того, чего у этой камеры нет:

| Карта | Значение |
|---|---|
| `DATE-OBS` | начало экспозиции, **UTC** |
| `DATE-LOC` | то же, местное время станции |
| `EXPTIME` | экспозиция, с |
| `BINNING` | биннинг |
| `READSPD` | настройка `READOUTSPEED`: целое `1` или `2`, не мегагерцы |
| `FILTER` | позиция колеса; `0` — дома либо неизвестно |
| `CCD-TEMP` | температура сенсора; нет показания — `-999.0` |
| `IMAGETYP` | `LIGHT` или `DARK` |
| `OBSMODE` | `sun`, `time` или `dark` |
| `INSTRUME`, `VENDOR`, `CAMSN`, `CAMVER` | модель, производитель, серийный номер, прошивка |
| `DRVVER`, `DCAMVER` | версии драйвера и DCAM API |
| `SITELAT`, `SITELON`, `SITEELEV` | координаты и высота площадки |

### sun_cycle

Набор ASI без карт об инструменте и программе: `INSTRUME`, `VENDOR`, `CAMSN`, `CAMVER`, `DRVVER`, `DCAMVER`, `BitDepth`, `CCDGain`, `DeviceID`, `Version`. Вместо них — карта `NAME`.

| Карта | Значение |
|---|---|
| `DATE-OBS`, `DATE-LOC` | начало экспозиции, UTC и местное |
| `EXPTIME`, `BINNING`, `READSPD`, `FILTER`, `CCD-TEMP` | как в `sun` и `time` |
| `IMAGETYP` | `LIGHT` или `DARK` |
| `OBSMODE` | `sun_cycle`, `sun_cycle_auto` (предварительная стадия) или `dark` |
| `SITELAT`, `SITELON`, `SITEELEV` | координаты и высота места съёмки |
| `ADCFULL` | полная шкала интенсивности |
| `NAME` | `japan.name` |
| `SKYMEAN` | измеренное среднее по кадру, АЦП; на каждом кадре |
| `SPLITNUM`, `SPLITIDX` | на сколько подкадров поделён слот и номер подкадра с единицы; только у разбитого слота |
| `Binning`, `CCDTemp`, `Exposure` | карты `imagerd_rt`, как у ASI |
| `ReadoutSpeed` | **строка** `"1 (slow, low noise)"` или `"2 (fast)"` |
| `SEQNO` | номер кадра из `seqno.txt` |
| `SiteID` | `japan.location.name` |
| `Latitude`, `Longitude` | координаты, округлены до сотых |
| `FilterWavelength`, `FilterPosition`, `FilterDescription` | тег, позиция и описание из `filters` |
| `FWTemp` | `-999.0`, датчика нет |
