# Камера Infra

Камера Tanho THCAMSW1300 (сенсор Sony IMX990-AABA-C), SWIR-диапазон, 12-битный АЦП. Снимает на заданных секундах каждой минуты, пока текущее время попадает в интервал [файла расписания](Schedules.md#файл-интервалов-canon-и-infra).

```bash
python main.py --type infra
```

Отсчёты приводятся к общей [шкале 0–65535](Intensity-Scale.md) сразу после деинтерливинга.

## Подключение

```bash
echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="aa55", ATTR{idProduct}=="8866", MODE="0666", GROUP="plugdev"' \
    | sudo tee /etc/udev/rules.d/99-sw1300-camera.rules
sudo udevadm control --reload-rules && sudo udevadm trigger
```

Библиотека `libTanhoAPI.so` лежит в `infra_lib/`. На Windows камера не поддерживается.

## Параметры

| Ключ | По умолчанию | Описание |
|---|---|---|
| `instance_name` | `""` | имя экземпляра; пусто — `Infra_<узел>` |
| `output_dir` | `""` | каталог для снимков |
| `schedule_file` | `""` | путь к файлу расписания (время в интервалах — UTC) |
| `capture_seconds` | `[0, 30]` | секунды каждой минуты для съёмки |
| `exposure_us` | `1000.0` | экспозиция, мкс |
| `gain` | `0` | усиление, 0–120 |
| `roi` | `1280x1024` | область захвата: полный кадр или полоса `1280x256` |
| `save_format` | `tiff` | `tiff` — 16 бит, `png` — 8 бит с нормализацией, `fits` — с метаданными |
| `overexposure` | выключено | разбивка пересвеченного кадра, см. [ниже](#защита-от-пересветки) |

Кадры называются по местному времени и никогда не перезаписываются: повторное имя (перевод часов назад) получает суффикс `_2`, `_3` и так далее.

`DATE-OBS` в FITS — начало экспозиции (UTC), а не время записи файла. Если параметр камеры изменён на лету, кадр, попавший на момент изменения, пропускается. Смена ROI сохраняет экспозицию (камера сбрасывает её сама).

## Защита от пересветки

Секция `overexposure`, та же, что у ASI и SPTT: см. [Управление интенсивностью](Intensity-Control.md#камеры-с-тиками-sptt-и-infra). Предварительной стадии у Infra нет: камера снимает по файлу интервалов, без высоты Солнца.

```json
"infra": { "overexposure": { "enabled": true, "threshold": 55000.0, "max_splits": 4 } }
```

- Мёртвое время — измеренный интервал между кадрами потока минус экспозиция. Пока поток не снял два кадра подряд, защита ждёт.
- Подкадр должен длиться с мёртвым временем не меньше секунды, поэтому экспозиции в миллисекунды не делятся. В логе об этом одна строка.
- Экспозиция подкадра держится между тиками и меняется только вместе с числом подкадров: каждая смена стоит потоку кадр-два. `focus_app.py` и статус показывают заданную `exposure_us`.
- `SKYMEAN`, `SPLITNUM` и `SPLITIDX` пишутся только в FITS. TIFF и PNG шапки не имеют, подкадры там различаются только временем в имени.
- Тёмных кадров нет, пьедестал задаётся ключом `bias`.

## Live Preview в GUI

На вкладке **Infra Camera** есть встроенный поток для настройки резкости и параметров:

1. Нажмите **Connect**.
2. Нажмите **Live Preview**.
3. Настройте экспозицию, усиление и ROI. Изменения применяются немедленно.
4. Нажмите **Stop Preview**.

Live Preview и измерения по расписанию работают независимо. Измерения во вкладке идут тем же кодом, что и `main.py --type infra`, включая защиту от пересветки. Во время измерения кнопки Set exposure/gain/ROI отказывают. Вкладка принимает `roi` от `focus_app.py`.
