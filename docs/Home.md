# Every Camera

Программа управления камерами наблюдательных станций. Одна программа ведёт шесть типов камер в консольном (headless) или графическом (PyQt5) режиме.

| Тип (`--type`) | Камера | Данные |
|---|---|---|
| [`cannon`](Camera-Canon.md) | Canon DSLR через gphoto2 | JPEG |
| [`sptt`](Camera-SPTT.md) | CSDU-429/423, CSDU-285C по USB | FITS |
| [`infra`](Camera-Infra.md) | Tanho SW1300 SWIR | TIFF, PNG или FITS |
| [`asi`](Camera-ASI.md) | всенебный имиджер: Princeton PIXIS (PICAM) и колесо фильтров | FITS |
| [`japan`](Camera-Japan.md) | всенебный имиджер: Hamamatsu (DCAM-API) и колесо фильтров | FITS |

Отдельные программы:

- [`monitor_app.py`](Monitor.md) — состояние всех камер плитками;
- [`viewer_app.py`](Viewer.md) — просмотр любого снятого кадра;
- [`focus_app.py`](Focus.md) — живой поток и настройка резкости;
- [`setup_app.py`](Setup-Wizard.md) — мастер настройки;
- [`sentinel.py`](Alerts.md) — сторож: шлёт письма об отказах и замечает падение основной программы.

## С чего начать

1. [Установить зависимости](Install.md) для своей роли машины.
2. [Заполнить конфигурацию](Setup-Wizard.md) мастером настройки.
3. [Запустить камеру](Quick-Start.md) и проверить её в [`focus_app.py`](Focus.md).
4. Для постоянной работы — поставить [службу systemd](Systemd.md) и указать [адреса для оповещений](Alerts.md).
