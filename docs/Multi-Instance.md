# Несколько экземпляров

Сколько угодно копий every-camera работают в одной сети и на одной машине с **одинаковыми** настройками сервера. Новые порты и имена придумывать не нужно.

## Имя экземпляра

По умолчанию это `{камера}_{node_name}`, например `ASI_Tory-1`. Префиксы: `Cannon`, `SPTT`, `Infra`, `Sentry`, `ASI`, `JAPAN`. Значение `instance_name` в секции камеры заменяет его.

Если имя уже занято живым процессом на этой машине, добавляется порядковый номер:

```
[WARN] Instance name 'ASI_Tory-1' is already used by another process on this
       machine — running as 'ASI_Tory-1-2'.
```

Имя резервируется блокировкой файла в `~/.every_camera/instances/` (`flock` на Linux, `msvcrt` на Windows). Упавший процесс освобождает имя автоматически, и следующий запуск получает его без суффикса.

От имени зависят файл лога и `preview_{экземпляр}.*`, поэтому уникальное имя разводит их все сразу.

## Порт LAN-сервера

`server.port` — предпочтительный порт. Если он занят, сервер поднимается на следующем свободном в пределах `server.port_search` (по умолчанию 20 портов):

```
[INFO] Port 8765 is busy — this instance took 8766. config.json is unchanged;
       the port is chosen per run.
```

В конфиг ничего не записывается, поэтому `config.json` остаётся одинаковым на всех узлах. `"port_search": 0` разрешает использовать только `port`.

## Обнаружение

Зонд рассылается и в multicast-группу `239.255.42.99:45455`, и широковещательно:

- широковещательную датаграмму ядро отдаёт ровно одному сокету, а multicast копирует всем вступившим в группу, поэтому второй экземпляр на машине тоже виден;
- broadcast нужен для коммутаторов без IGMP-querier и узлов со старой версией.

```bash
$ python discovery.py --timeout 2
Tory-1               ASI_Tory-1           asi      http://192.168.1.42:8765
Tory-1               ASI_Tory-1-2         asi      http://192.168.1.42:8766
```
