# Режим настройки

Отсутствующее, пустое или испорченное расписание — не ошибка. Камера поднимается в **режиме настройки**, чтобы её можно было навести через `focus_app.py`.

В этом режиме:

- камера открывается, LAN-сервер работает, `focus_app.py` подключается;
- плановые съёмки не выполняются, в архив ничего не пишется;
- у ASI и Japan не снимаются тёмные кадры, но затвор открывается: через закрытый затвор наводить нечем;
- статус — `setup`, он виден в мониторе и в `/api/status`, а в `/api/info` выставлен флаг `setup_mode`, и `focus_app.py` рисует метку **SETUP**.

В консоли это выглядит так:

```
[WARN] Setup mode: schedule file not found: /home/alex/data/schedule.txt.
[INFO] No scheduled captures will be taken. Connect focus_app.py to adjust focus
       and camera parameters; add a schedule and restart to begin measuring.
[INFO] Focus this camera with: python focus_app.py --host 192.168.1.42 --port 8765
```

## Когда камера входит в режим

- Путь к расписанию не задан.
- Файл не найден, нечитаем или двоичный.
- Файл пуст, состоит из комментариев или все строки некорректны.
- ASI, Japan: пустой `schedule`.

Принудительно, даже при заполненном расписании:

```bash
python main.py --type asi --setup
```

Когда расписание появится, перезапустите программу, и она начнёт измерения. В GUI пустая таблица расписания не блокирует кнопку запуска: вкладка стартует в режиме настройки.

Камера также приостанавливает расписание, когда оператор подключается через `focus_app.py`: см. [Настройка резкости](Focus.md#что-происходит-с-измерениями).
