# Солнце и IERS

ASI и Japan считают высоту Солнца через `astropy` (`cameras/common/sun.py`). Для перевода UTC в UT1 `astropy` нужна таблица параметров вращения Земли. Программа **не скачивает её**, чтобы недоступность сети не остановила ночь.

## Почему загрузка отключена

По умолчанию `astropy` обращается к `datacenter.iers.org` и `maia.usno.navy.mil`, которые регулярно недоступны даже при рабочем интернете. Настройки по умолчанию приводят к двум проблемам:

- `auto_download = True`: первый расчёт Солнца уходит в сеть, и при недоступном адресе это `remote_timeout` на каждый URL прямо внутри цикла измерений. Слот опаздывает.
- `auto_max_age = 30` и `iers_degraded_accuracy = 'error'`: когда значения встроенной таблицы старше месяца, а скачать не удалось, `astropy` бросает исключение. Оно останавливает измерения.

Такой отказ выглядит так:

```
08:57:50 [WARN ] failed to download https://datacenter.iers.org/data/9/finals2000A.all
08:57:50 [ERROR] Measurement loop failed: interpolating from IERS_Auto using
                 predictive values that are more than 30.0 days old
08:57:52 [INFO ] Japan worker stopped — 0 light, 0 dark, 1 error(s)
```

## Что делает программа

Перед первым расчётом Солнца она отключает скачивание, снимает проверку возраста таблицы и убирает ошибку потери точности. В лог один раз за запуск пишется:

```
Earth rotation: bundled IERS table, no network (solar altitude within 0.01°)
```

## Точность

Теряется поправка UT1−UTC, она меньше секунды. Солнце проходит 15″ за секунду времени, поэтому худший случай — около **0,004° по высоте Солнца**. Пороги задаются целыми градусами, так что разница неизмерима.

## Если нужна свежая таблица

Для станции, которая достаёт до этих адресов, задайте в `env.sh` или `env.cmd`:

```bash
export EVERY_CAMERA_IERS_AUTO=1
```

`astropy` снова будет ходить в сеть, но проверка возраста остаётся снятой, и исключения не будет ни при какой настройке. Цена — ожидание на первом расчёте каждого запуска, если адрес не отвечает.

Другой вариант — указать зеркало в конфиге `astropy`: `~/.astropy/config/astropy.cfg`, ключ `iers_auto_url`.
