# Камера Canon

Canon DSLR через gphoto2. Секция конфигурации и тип запуска — `cannon`. Снимает JPEG на заданных секундах каждой минуты, пока текущее время попадает в интервал [файла расписания](Schedules.md#файл-интервалов-canon-и-infra).

```bash
python main.py --type cannon
```

## Подключение

Обычно работает без настройки. Если камера занята системой, завершите gvfs:

```bash
sudo pkill gvfsd-gphoto2
```

На Windows камера не поддерживается.

## Параметры

| Ключ | По умолчанию | Описание |
|---|---|---|
| `instance_name` | `""` | имя экземпляра; пусто — `Cannon_<узел>` |
| `output_dir` | `""` | каталог для JPEG |
| `schedule_file` | `""` | путь к файлу расписания |
| `capture_seconds` | `[0, 30]` | секунды каждой минуты для съёмки |
| `camcfg_file` | `""` | `.ini` с настройками камеры; пусто — `camcfg_<Модель>.ini` рядом с программой |
| `shutterspeed` | `""` | выдержка; пусто — берётся из `camcfg_*.ini` |

Файл `camcfg_*.ini` создаётся автоматически при первом запуске и находится в `.gitignore`. Относительный путь в `camcfg_file` отсчитывается от каталога программы.

## Выдержка

`shutterspeed` пишется так, как её называет сама камера: `"1/125"`, `"10.3"`, `"30"`. Значение применяется поверх `camcfg_*.ini`, поэтому основная настройка лежит в `config.json` и переносится вместе с ним.

- Список выдержек зависит от модели. У Canon EOS 6D это значения от `30` до `1/4000`.
- Если камера не поддерживает значение, при запуске выводится ошибка со списком допустимых, а съёмка продолжается со старой выдержкой.
- Камера должна быть в ручном режиме. Если `autoexposuremode` или `shootingmode` не `Manual`, выводится предупреждение: в P, Av и Tv камера подбирает выдержку сама.

Выдержку можно менять на лету через [`focus_app.py`](Focus.md). `config.json` задаёт только состояние на старте.
