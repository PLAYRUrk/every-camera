# Просмотрщик кадров

`viewer_app.py` только показывает кадры: ничего не снимает и не меняет настройки камеры. Работает на Windows и Linux, драйверы камер не нужны.

```bash
python viewer_app.py                      # найти камеры в локальной сети
python viewer_app.py --host 192.168.1.5   # сразу подключиться
python viewer_app.py --host 192.168.1.5 --port 8766
python viewer_app.py --host 10.0.0.5 --via 192.168.1.5:8765   # через шлюз
```

Архив читается с диска камеры, поэтому кадры доступны, даже если камера занята измерениями или её рабочий поток завис.

## Работа с архивом

1. **Search LAN** — поиск камер. Если обнаружение заблокировано, введите `хост:порт` вручную.
2. Список дат и кадров: можно открыть любой снятый кадр.
3. **Latest frame** — последний кадр. **Follow live** обновляет его каждые 3 секунды.
4. **Contrast** — растяжка гистограммы: min–max, перцентильная (0,5–99,5 %, лучше видно слабые детали рядом с яркими пикселями) или без растяжки.
5. **Save original…** — скачать исходный файл без преобразований.

Раз в пять секунд просмотрщик проверяет, вырос ли архив, и перечитывает его только в этом случае. Раскрытые ветки, прокрутка и выбранный кадр при обновлении сохраняются. Кнопка **Reload** нужна, если каталог изменился иначе, например файлы удалили вручную.

Архив обходится вглубь, поэтому плоские каталоги и дерево `ГГГГ/ММ/ДД` работают одинаково. Кадр с датой в имени открывается и по одному имени: сервер находит его в подкаталоге дня. Выход за пределы `output_dir` запрещён.

## Панель Frame info

Панель справа выключается одноимённым флажком. Порядок строк:

1. какой это кадр и когда снят;
2. что в нём измерено: размер, тип данных, минимум, максимум, среднее, доля насыщенных пикселей, шкала интенсивности;
3. весь FITS-заголовок таблицей.

Ниже — гистограмма по всему диапазону 0–65535 с логарифмической высотой столбцов. Она показывает, сидит ли кадр в пьедестале, размазан по диапазону или упёрся в насыщение.

В режиме **Follow live** панель тоже работает: камера сообщает путь только что записанного файла, а сервер читает из него заголовок. Если файла нет (режим настройки, Canon), панель показывает файловые данные, измеренное и то, что опубликовала камера.

## Группировка по циклам

Номер цикла нигде в кадре не записан. Просмотрщик может угадать период по возврату одного фильтра, но ночь с потерянным слотом может сдвинуть такую оценку.

Поэтому камера сообщает расписание в `/api/info`: режим, период и опорное время, в том числе в UTC, потому что имена кадров в UTC. При подключении поля **Period** и опорное время заполняются этими значениями. Если поправить поля вручную, расписание камеры их больше не меняет.

Архив, отданный без камеры, тоже может знать период:

```bash
python -m frame_server --output-dir /data/japan --camera-type japan --config config.json
```

## Разностный кадр (только Japan)

Флажок **Filter difference** рядом с **Group by cycle and filter**, по умолчанию выключен. При выборе ветки фильтра внутри цикла рядом открывается второе окно с обработанным кадром:

```
A = первый кадр этого цикла для этого фильтра
B = последний кадр предыдущего цикла для того же фильтра
D = последний кадр этого цикла для того же фильтра

k0 = clamp(1 − (t_A − t_B) / T, 0, 1)
k1 = clamp(1 − (t_D − t_A) / T, 0, 1)

результат = A − (B·k0 + D·k1) / 2
```

Вес тем ближе к 1, чем меньше промежуток. `T` задаётся в этом окне, по умолчанию это период цикла, и результат пересчитывается на лету. В окне видны `k0`, `k1`, промежутки и имена трёх кадров. Растяжка берётся из того же **Contrast**.

Окно не открывается, когда считать нечего: у первого цикла ночи нет предыдущего, у свежего цикла ещё нет последнего кадра, а при пропуске в архиве более старый цикл предыдущим не назначается. Причина пишется в строку состояния.

Кадры выбирает просмотрщик, а считает камера (`/api/composite`): три кадра — это около 24 МБ по сети против 200 КБ готового JPEG.

## Камера без прямого маршрута

`--via` называет камеру, которая сходит за кадрами вместо вас:

```bash
python viewer_app.py --host 10.0.0.5 --via 192.168.1.5:8765
```

Работает всё: архив, разностные кадры, последний кадр. Кнопка **Frames…** в мониторе подставляет `--host` и `--via` сама.

## Камера за пределами локальной сети

В поле адреса или в `--host` можно вставить адрес [туннеля](Tunnel.md) из письма:

```bash
python viewer_app.py --host https://quiet-owl-test.trycloudflare.com
```

`--via` тоже принимает адрес туннеля: так открывается соседняя камера той же станции.
