# Быстрый старт

Перед первым запуском [установите зависимости](Install.md) и [заполните конфигурацию](Setup-Wizard.md).

## Консольный режим

Не требует дисплея.

```bash
python main.py --type cannon     # Canon DSLR
python main.py --type sptt       # CSDU-429/423/285C: модель определяется по USB ID
python main.py --type infra      # SW1300 SWIR
python main.py --type asi        # всенебный имиджер PIXIS
python main.py --type japan      # всенебный имиджер Hamamatsu

python main.py --type asi --verbose   # строки лога вместо живого экрана
```

Что показывает экран, описано на странице [Консоль измерений](Measurement-Console.md).

## Графический режим

```bash
python main.py                    # автоматически, если есть дисплей и не задан --type
python main.py --gui              # явно
python main.py --gui --type asi   # только одна камера
```

## Параметры main.py

| Параметр | Назначение |
|---|---|
| `--type TYPE` | тип камеры; допускается метка после дефиса (`sptt-north`), см. [Службы systemd](Systemd.md#несколько-камер-sptt-на-одном-пк) |
| `--gui` | принудительно графический режим |
| `--config PATH` | другой файл конфигурации; по умолчанию `config.json` рядом с программой |
| `--preview` | [режим предпросмотра](Preview.md), только в консоли |
| `--setup` | [режим настройки](Setup-Mode.md): камера работает для фокусировки, в архив ничего не пишется |
| `--probe` | [опрос камеры](Probe.md): `asi`, `japan`, `sptt` |
| `--verbose` | обычные строки лога вместо живого экрана |

Те же аргументы принимают [`run.sh`](Run-Script.md) и `run.cmd`.

## Программы наблюдателя

```bash
python monitor_app.py     # плитки всех камер, найденных в локальной сети
python viewer_app.py      # любой кадр из архива камеры
python focus_app.py       # живой поток и настройка резкости
```

## Остановка

| Как запущено | Что делать | Что произойдёт |
|---|---|---|
| Консоль | `Ctrl+C` | потоки останавливаются штатно |
| ASI, Japan | первый `Ctrl+C` или `SIGTERM` | драйвер доснимает кадр и пишет финальные тёмные кадры |
| ASI, Japan | повторный сигнал | немедленный выход без финальной серии |
| systemd | `systemctl stop` | `SIGTERM`, то же, что `Ctrl+C`; см. [Службы systemd](Systemd.md#остановка-не-мгновенная) |
| GUI | закрыть окно | GUI заново читает `config.json` с диска и записывает обратно только поля своих вкладок: `output_dir`, `capture_seconds`, `save_format` Infra, `output_dir` и `camera.backend` ASI и Japan. Если `config.json` не удалось прочитать, не записывается ничего |

При включённом `cooling.warm_on_exit` камера ASI отогревает сенсор при выходе.

При остановке удаляется файл статуса, и камера сразу исчезает из монитора и просмотрщика. LAN-сервер останавливается вместе с измерениями. Чтобы архив оставался доступен, запустите [сервер отдельно](Frame-Server.md#просмотр-архива-без-камеры).

Подробнее о финальных тёмных кадрах: [Тёмные кадры и фазы](Darks-And-Phases.md).
