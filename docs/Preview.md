# Режим предпросмотра

`--preview` непрерывно перезаписывает один файл рядом с программой на максимальной частоте, без расписания. Работает только в консольном режиме.

```bash
python main.py --type infra --preview
```

| Камера | Файл | Что происходит |
|---|---|---|
| Canon | `preview_<экземпляр>.png` | непрерывная съёмка |
| SPTT | `preview_<экземпляр>.png` | непрерывная съёмка |
| Infra | `preview_<экземпляр>.fits` | непрерывная съёмка |
| ASI | `preview_<экземпляр>.fits` | непрерывная съёмка |
| Japan | `preview_<экземпляр>.fits` | непрерывная съёмка |

Имя экземпляра описано на странице [Несколько экземпляров](Multi-Instance.md#имя-экземпляра).

Для наведения по сети удобнее [`focus_app.py`](Focus.md).
